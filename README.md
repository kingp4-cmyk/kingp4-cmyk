## Projects

### My Sweet Ajanda

A personal web project I built for planning, journaling, and studying.

It includes a customizable calendar, daily tasks, personal journals, and a real-time study club. Users can also personalize their experience with different themes, avatars, and stickers.

I used Firebase for user data and real-time features, and Supabase for storing journal media.

**Technologies:** HTML, CSS, JavaScript, Firebase, Supabase

[Live Website](https://kingp4-cmyk.github.io/my-sweet-planner/) | [Repository](https://github.com/kingp4-cmyk/my-sweet-planner)

**Technologies:** Node.js, Express.js, RabbitMQ, Docker
